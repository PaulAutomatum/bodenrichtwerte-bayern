# Bodenrichtwerte Bayern

Interaktive Karte der Bodenrichtwertzonen in Bayern (Stichtag 01.01.2026). Die Zonen werden beim Verschieben der Karte direkt aus dem WMS „Bodenrichtwerte in Bayern 2026“ (LDBV, gdi.bayern.de) abgefragt.

**Live:** https://paulautomatum.github.io/bodenrichtwerte-bayern/

- Daten: Gutachterausschüsse in Bayern über das LDBV; der Dienst ist kostenfrei für private Nutzung. Manche Gutachterausschüsse geben ihre Werte nur gegen Gebühr heraus, diese Zonen erscheinen grau.
- Die Karte ersetzt keine amtliche Bodenrichtwertauskunft.
- Grundkarte: Webkarte © Bayerische Vermessungsverwaltung, CC BY 4.0.
- Ortssuche: Nominatim, © OpenStreetMap-Mitwirkende.
